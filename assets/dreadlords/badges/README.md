# Dread Lords: Villain Tycoon badges

This set contains 13 circular-crop-safe badge icons for Roblox.

- `upload/` contains the finished 512 x 512 PNG files to upload in Creator Dashboard.
- `source/` contains the 1254 x 1254 generated masters.
- `badges.json` contains the final badge names, descriptions, and award criteria.
- `PROMPTS.md` records the art direction and subject prompt for each icon.

The shared visual language is dark forged iron, stylized bone, violet magic, ectoplasm green, and antique gold. The artwork uses chunky, Roblox-like forms and keeps all important details inside the circular crop. There is no red blood, gore, wounds, or realistic horror.

Roblox currently allows five free badge creations per game in each 24-hour GMT period. Creating more during the same period costs Robux, so upload this 13-badge set across three free windows unless you intend to pay for the additional creations.

`Dreamer` follows the supplied badge table and is described as unlocking the Dream Lord. If the shipped villain is named `Warlock` instead, update the public description before creating that badge.
