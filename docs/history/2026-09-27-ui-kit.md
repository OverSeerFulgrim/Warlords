# The UI kit on the menus (2026-09-27)

The commissioned menu art sat unreferenced in a gitignored `_imgtmp_ui_kit/` folder. It was the
only copy. It is now committed, cut into runtime pieces, and worn by every full-screen menu and
dialog.

## Where the art lives now

- **Masters:** `assets/official/_originals/UI/` holds the four finished sheets:
  - `Necromancer_UI_Main_Menu_Frame.png`;
  - `…_Popup_Frame.png`;
  - `…_Controls_4x4.png` (buttons, panels, bars, divider, dropdown, tick boxes, radio buttons);
  - `…_Icons_4x4.png`.

  The four raw `source_*.png` generations sit beside them. `_originals/` has a `.gdignore`, so
  Godot never imports them.
- **Cleaning:** the masters were cut from a red key. `tools/clean_red_chroma.py` is the script
  that did it, moved out of the temp folder.
- **Runtime pieces:** `tools/make_ui_kit.py` cuts the masters into `assets/official/ui/UI_*.png`,
  downscaled to the size they draw at. Re-run it if a master changes. It prints the margins, and
  `UiKit.gd`'s constants must match them.
  - The button and popup art have a crest in the middle of the top edge. A plain nine-slice would
    stretch the crest with the edge, so the script rebuilds each edge from a plain run of border.
  - The popup's crest is kept as its own image (`UI_Panel_Crest.png`), and `UiKit.add_crest()`
    draws it over the panel.
  - The inside of each frame is filled with the HUD's dark violet at 96%.
- **`_imgtmp_ui_kit/`** was deleted after the move.

## What wears it

`scripts/ui/UiKit.gd` provides the pieces:
- **`menu_theme()`:** one cached Theme covering Button plates (normal, hover, pressed, disabled,
  focus), CheckBox, HSeparator and the scroll bar. A CheckBox inherits Button's theme items, so the
  theme gives it `StyleBoxEmpty` plates and the kit's tick-box icons.
- **`panel_style()`:** the popup frame.
- **`add_crest()`:** draws the crest over a panel.
- **`divider()`:** the gem divider, in place of a plain HSeparator.
- **`bar()` / `set_bar()`:** the framed green bar.
- **`fit_scroll()`:** sizes a dialog's scroll box to its content, capped to the window.

Which screens use it:
- **Title:** the main-menu frame, as large as the window allows at its own shape. The menu sits
  inside the frame and scrolls if the window is short, which the Controls page needs at 760 px.
  The buttons are 300 px wide and centred.
- **Pause menu and the abandon confirm, the flee picker, the Lair, the Items window:** the popup
  frame and crest, with the theme on the menu's root. `PauseMenu.panel_style()` now returns
  `UiKit.panel_style()`, so everything that used the old flat violet box gets the frame.
- **Run-end screen:**
  - the popup frame and gem dividers;
  - the XP bar is now the kit bar;
  - the body scrolls inside the frame, because the thicker frame plus five dividers no longer fit a
    760 px window.
- **Items window:** its scroll box now fits its content. Before, it was a fixed 560 px, which left
  a tall empty panel when the bag was empty.

**Not changed:** the floating HUD keeps `HudStyle`'s slim boxes. The kit's plates and bars do not
read at the HUD's 8 px bars and 12 px chips. The in-world inspector buttons stay as they were.

**Not wired yet:** the icon sheet (heart, bones, essence, wood, stone, food, hood, house, horned
skull, crown, sun, moon, boot, blades, gear, lock) and the controls sheet's gem slots, radio
buttons and dropdown. They are kept only as masters. A later HUD pass can cut them with the same
script.
